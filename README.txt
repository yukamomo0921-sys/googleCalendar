くらしメンテ v33

今回の変更：
・タイマー、工程の進行状況、端末内の実行状態はクラウドに保存しないようにしました。
・習慣の設定、NFCタグ、完了履歴、ポイント関連データは同期対象です。
・クラウドから習慣設定を受信しても、その端末で進行中のタイマーや工程状態を上書きしないようにしました。
・完了ログはIDを使って統合し、同じログが重複しにくいようにしています。
・Service Workerのキャッシュ名をv33に更新しました。

GitHub Pagesへの反映：
1. ZIPを展開します。
2. 展開した中のファイル（index.html、service-worker.js、manifest.webmanifest、icon-192.png、icon-512.png）をGitHubリポジトリのトップ階層にアップロードし、既存ファイルを置き換えます。
3. README.txtは任意です。GitHubのコミットを保存します。
4. 公開サイトを開き直します。古い画面が残る場合は、Safari/Chromeを完全に閉じて再度開きます。

注意：実機でNFC・Firebaseの動作確認はまだできていません。アップロード後、スマホでNFC開始→NFC完了→Macで履歴確認の順にテストしてください。既存のFirebaseデータは削除しません。
